# Install PiStick for iPhone and iPad

PiStick requires iOS or iPadOS 17 or newer and is distributed through Apple TestFlight.

## 1. Request access

Email [tnichol00@gmail.com](mailto:tnichol00@gmail.com) and ask to join the PiStick TestFlight. Include the Apple ID email address used on the iPhone or iPad.

## 2. Install through TestFlight

1. Install [TestFlight from the App Store](https://apps.apple.com/app/testflight/id899247664).
2. Open the TestFlight invitation sent to the requested Apple ID.
3. Accept the invitation.
4. Select **Install** beside PiStick.
5. Open PiStick after installation finishes.

## 3. Complete first-time setup

1. Enter either the long TMDB **API Read Access Token** or the shorter TMDB v3 API key.
2. Select **Save and Continue**.

PiStick validates the credential with TMDB and then opens the profile screen.

## Update PiStick

Open TestFlight and select **Update** when a new PiStick build is available. TestFlight builds expire after 90 days, so install a newer build before the current one expires.
